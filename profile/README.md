### What we do

Serve OS is a technology delivery partner. We take client projects from spec to production and manage them long-term — engineering, infrastructure, and ongoing support — so our clients don't have to build an in-house team to ship software.

- **Product engineering** — web & mobile apps, from MVP to scale
- **Managed delivery** — we own the roadmap execution, not just the code
- **Ongoing ops** — deployment, monitoring, and support after launch

### How we work

Every client engagement gets its own set of repos (frontend, backend, admin) under this org, with:
- Protected `main` branches and required reviews
- Team-based access control (no ad-hoc collaborator invites)
- Secret scanning & push protection enabled by default
